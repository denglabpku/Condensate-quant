1.1 当前代码仓库总览
当前 Condensate-quant 仓库用于活细胞超分辨多通道图像中生物分子凝聚体的检测、分割和定量。主要包含以下功能：
1. 多通道色差校正。
2. Noise2Void 自监督去噪模型训练、测试和 ONNX 导出。
3. MATLAB 中基于 ONNX 的滑窗推理去噪。
4. Richardson-Lucy 反卷积。
5. 细胞核掩膜生成。
6. HMRF 凝聚体分割。
7. LoG foci 定位。
8. RNA/DNA/Enhancer/Promoter foci 到凝聚体边界、界面、中心或质心的距离计算。
9. RNA 阳性和 RNA 阴性细胞分组统计。
10. 散点图、密度等高线图和结果检查图导出。

1.2 多通道图像像差校正
1.2.1 荧光微球玻片和采集
图像色差校正基于 TetraSpeck 多色荧光微球完成。100 nm 微球适合估计 488/560/640 等通道之间的偏差；由于 405 通道信号可能较弱，405 通道校正可额外使用 500 nm 微球。

推荐采集方式：
1. 使用高质量 #1.5H 盖玻片。
2. 稀释并充分超声、涡旋微球，避免聚集。
3. 盖玻片中央滴加微球悬液，待水分挥发后封片。
4. 采集 LiveSR 或 Confocal 多通道 z-stack。
5. 推荐通道顺序为 640、560、488、405。
6. z step 可设为 100 nm，覆盖约 2.8 um，实际层数和范围可根据系统和样品调整。
7. 使用 Fiji TrackMate 的 LoG 检测对每个通道内微球中心做 3D 定位，并导出 CSV。

每组校准数据通常包含：
*_405channel.csv
*_488channel.csv
*_560channel.csv
*_640channel.csv

注意事项：
1. 微球密度需要足够高，但应避免大量粘连。
2. 定位时应剔除靠近边界、粘连、饱和或质量低的微球。
3. 405 通道与其他通道在 z 方向可能存在明显 shift，后续校正后可能出现某些通道第一层或最后一层全黑。

1.2.2 生成通道变换矩阵
主脚本：
Step0_channel_alignment/script_get_transformation_matrix.m

主要功能：
1. 读取各通道 TrackMate 导出的 CSV 定位结果。
2. 对不同通道间的 beads 坐标进行匹配。
3. 使用 MATLAB 几何变换函数估计 2D 和 3D transformation。
4. 输出 tform 文件，例如 tform_20260123.mat。
5. 可视化校正前后通道间偏移。

需要修改的内容：
1. filename_list：指向自己的 beads 校准数据。
2. 输入通道是否齐全。
3. 若脚本中为了填充 z 范围而对 z 坐标加入随机扰动，需要根据实际采集范围确认是否保留。

1.2.3 应用通道校正
主程序：
Step0_channel_alignment/ImageRegistrator.mlapp

使用方式：
1. 打开 MATLAB App。
2. 选择输入图像或输入文件夹。
3. 选择输出目录。
4. 选择 transformation matrix 文件。
5. 选择成像模式，例如 Live-SR 或 Confocal。
6. 导出校正后的 OME-TIFF。

当前说明中需要特别强调：
1. 如果图像包含 405/488/560/640 多通道，通常会将所有通道向 488 nm 参考通道校正。
2. 如果只有 560 和 640 两个通道，通常将 640 通道向 560 通道校正。
3. MATLAB 导出的 OME-TIFF 建议用 Bio-Formats 在 Fiji 中打开。
4. 如果后续 MATLAB 脚本无法正确读取 OME-TIFF，可先用 Fiji 宏批量另存为标准 stack，但要确认通道、z 和 time 的维度没有被打乱。

1.4 PSF 采集与 Richardson-Lucy 反卷积
PSF 文件位于：
PSF/psf_SR_channel405_2D.tif
PSF/psf_SR_channel488_2D.tif
PSF/psf_SR_channel561_2D.tif
PSF/psf_SR_channel642_2D.tif
PSF/psf_noSR_channel405_2D.tif
PSF/psf_noSR_channel561_2D.tif
PSF/psf_noSR_channel642_2D.tif

PSF 的采集和提取原则：
1. 使用直径小于成像系统分辨率的荧光微球。
2. 荧光发射波长应尽量匹配后续样品通道。
3. 采集大视野 z-stack，提取多个孤立 beads。
4. 对多个 beads 的 PSF 做平均和归一化，使 PSF 总信号为 1。

MATLAB 反卷积函数：
Function/deconv_fixed_iter.m

当前主脚本中的反卷积设置通常为：
pad = 20
iteration = 20

不同流程中的通道处理：
1. Step2 时间序列凝聚体脚本默认对 channel 1 使用 561 nm PSF 做反卷积。
2. 3color-RNA-2Condensate 对 488、560、640 三个通道分别使用对应 PSF 反卷积；随后把 RNA 通道重新替换回 denoised 版本，用于 foci 定位。
3. 4color-DNA-RNA-2Condensate 对 405、488、560、640 通道分别处理；foci 通道在后续分析中也会被替换为 denoised 版本。
4. 4color-PRE-Condensate 对 405、488、560、640 通道处理，并根据实验文件夹选择 BRD4 或 OCT4 作为 condensate 通道。
5. 3color-Promoter_RNA_SCR 对 405、488、560 三个 foci 通道处理，主要输出 foci 距离和定位误差，不做凝聚体分割。

1.5 Step2：时间序列凝聚体去噪、反卷积、分割和统计
主目录：
Step2_deconvolution-segmentation/

主脚本：
denoise_deconv_condensate_2D_time_series_HMRF_boundary.m

适用场景：
1. 分析 OCT4 或 BRD4 等凝聚体通道的活细胞时间序列。
2. 不需要同时分析 DNA/RNA foci 到凝聚体的位置关系。
3. 需要得到凝聚体数量、面积、半径随时间变化的统计结果。

运行前需要修改或确认：
1. onnx_path：默认指向 onnx/N2V_3D_OCT4_BRD4_liveSR_125_8_E10_xy3z0.onnx。
2. is_GPU_avaliable：有 GPU 且 MATLAB 支持时为 true，否则改为 false。
3. use_accelerate：为 true 时 HMRF 在较低 resize_factor 上运行，再把阈值映射到高分辨率图像；可显著加快速度。
4. psf_SR_560：默认使用 PSF/psf_SR_channel561_2D.tif。
5. filepath_list：当前默认使用脚本所在目录 script_dir。
6. pixelSize：默认 95 nm。
7. resize_factor：默认 10。
8. min_radius：默认 50 nm。
9. min_partition_coefficient：Step2 当前为 1.25。
10. nclust：HMRF 聚类数，默认 7。
11. seg_point：HMRF 中被判定为凝聚体的类别阈值，默认 5。

主要处理流程：
1. 使用 Bio-Formats 读取 OME-TIFF 的 sizeX、sizeY、sizeZ、sizeC、sizeT，并构建 img_stack，维度为 Y、X、Z、C、T。
2. 对每个 z 和 channel 进行 N2V 去噪。脚本先减去图像均值，按 ONNX 输入尺寸提取滑窗 patch，逐 patch predict，再用 reconstructFromPatches 拼回整图。
3. 对去噪结果做 Richardson-Lucy 反卷积。
4. 导出去噪和反卷积 TIFF。
5. 使用 NucleusMask2 生成细胞核掩膜。
6. 对每一帧进行 HMRF 分割，得到凝聚体候选区域。
7. 使用 filter_condensates_Area_PC 按面积和分配系数过滤凝聚体。
8. 计算 CDcenter、CDinterface、CDboundary、CDmask、labels 和 area。
9. 保存 .mat 结果，并导出用于检查的 TIFF 和 HMRFseg.png。
10. 后半部分可从已有 .mat 文件重新载入 condensate_result，统计凝聚体数量、面积和半径。

输出文件：
样本输出文件夹与输入文件同名，例如 sample_name/
sample_name-denoised.tif
sample_name-denoised-deconv.tif
sample_name-HMRFseg.png
sample_name-CDcenter.tif
sample_name-CDinterface.tif
sample_name-CDboundary.tif
sample_name-CDmask.tif
sample_name.mat
condensate_statistics.mat

.mat 中的重要变量：
img_stack_deconv
nucleus_mask
resize_factor
pixelSize
condensate_result

condensate_result 字段：
CDcenter：凝聚体中心或局部中心点。
CDinterface：凝聚体界面区域。
CDboundary：凝聚体边界。
CDmask：二值凝聚体掩膜。
labels：每个凝聚体的 label 编号。
area：每帧每个凝聚体的面积，单位为 resize 后的像素数。

1.6 Step3：下游空间共定位分析总览
Step3_downstream_analysis/ 下当前包含四类分析：
1. 3color-RNA-2Condensate：RNA、OCT4、BRD4。
2. 4color-DNA-RNA-2Condensate：DNA、RNA、OCT4、BRD4。
3. 4color-Promoter-RNA-Enhancer-Condensate：Promoter、RNA、Enhancer/SCR、单个 Condensate。
4. 3color-Promoter_RNA_SCR：Promoter、RNA、Enhancer/SCR foci 距离和定位误差分析。

共同输入要求：
1. 已完成通道色差校正的 OME-TIFF 或 TIFF。
2. 每个细胞建议裁剪为单细胞图像，避免多个细胞干扰核分割和 foci 定位。
3. 图像高和宽应大于 N2V patch 尺寸。
4. 通道顺序必须与脚本中的 channel_labels 一致。
5. RNA 阳性和 RNA 阴性样本建议分别写入 Cell_with_RNA.txt 和 Cell_without_RNA.txt。
6. 文件名列表中若带单引号，当前脚本会用 strrep 去掉。
7. 多个脚本会把空行过滤掉：filename_list = filename_list(strlength(filename_list) > 0)。

共同参数：
pixelSize = 95 nm
resize_factor = 10
roi_width = 31
min_radius = 50 nm
nclust = 7
seg_point 或 seg_points = 5
overlap_factor = 0.25
pad = 20
deconvolution iteration = 20

共同输出：
1. 每个细胞一个 .mat 文件。
2. 每个细胞一个结果检查 png。
3. 每个细胞一个输出文件夹，内含 foci ROI、condensate ROI、HMRF 分割、CDmask、CDcenter、CDinterface、CDboundary 等 TIFF。
4. 每个批处理输出目录下有 Cell_analysis_errors.txt。

新增容错机制：
1. 每个批处理输出目录运行开始时会调用 initializeCellProcessingErrorLog。
2. 每个细胞处理包在 try/catch 中。
3. 若单个细胞失败，catch 中调用 cleanupCellProcessingResources 关闭 Bio-Formats reader、waitbar 和所有 figure。
4. logCellProcessingError 会记录时间、文件名、错误 ID、错误信息和 MATLAB stack。
5. 脚本随后 continue 到下一个细胞，避免整个批处理被单个异常文件中断。

1.11 核心函数说明
1.11.1 NucleusMask2
用途：
从指定通道或投影图中生成细胞核掩膜。

常见问题：
1. 如果视野内有多个细胞，函数可能选中面积最大或最亮的错误细胞核。
2. 如果 foci 不在 nucleus_mask 内，后续 log_detector_fft 可能找不到匹配 spot。
3. 当前 4color 脚本已经加入部分回退逻辑：优先用凝聚体或 OCT4 通道圈核，失败后尝试 DNA 通道。

建议：
1. 尽量裁剪单细胞。
2. 运行后首先检查单细胞 png 叠加图。
3. 若核分割失败，可以手动换通道、调整 NucleusMask2 参数，或剔除该细胞。

1.11.2 log_detector_3d_Sage 和 log_detector_fft
用途：
1. log_detector_3d_Sage 用于 3D z-stack 中检测 foci。
2. log_detector_fft 用于选定 z 层或 2D 图像中检测 foci 或 condensate 中心。

常见参数：
spot 半径 = 3
阈值可为 mean(channel(:))/5 或 0，再用质量分数筛选。

常见筛选逻辑：
1. 去掉 x 坐标靠近边界的 spot，例如 x > 5 且 x < sizeX - 5。
2. 选择 quality 最大的 spot。
3. RNA spot 与 DNA/Promoter spot 距离小于 5 pixel 时认为匹配；否则 RNA 阴性时用 DNA/Promoter spot 作占位。

1.11.3 HMRFseg4img
用途：
对凝聚体通道做考虑空间连续性的强度分割。

常见参数：
nclust = 7
beta 或平滑参数 = 0.1
收敛阈值 = 1e-8
seg_point = 5

当前代码中新增保护：
如果 HMRFseg.img_class >= seg_point 没有任何像素，脚本会 warning，并设置 local_thresh = inf，避免 min 空数组导致程序直接崩溃。

1.11.4 filter_condensates_Area_PC
用途：
按凝聚体面积和分配系数过滤 HMRF 分割结果。

输入：
labels
img
min_pixel_num
min_partition_coefficient
resize_factor

面积阈值：
min_pixel_num = min_radius^2 * pi / (pixelSize / resize_factor)^2

分配系数：
PC_max = max(inside_val) / mean(outside_val)
PC_mean = mean(inside_val) / mean(outside_val)

outside 区域定义：
对凝聚体 mask 分别膨胀 2 * resize_factor 和 3 * resize_factor，取二者之间的环形区域，并要求 labels == 0。

过滤规则：
1. inside 像素少于 1 或 outside 像素少于 5，删除该 label。
2. area_pixel < min_pixel_num，删除。
3. PC_max < min_partition_coefficient，删除。

注意：
当前函数中的中文注释有编码显示问题，建议后续统一保存为 UTF-8。

用途：
从二值凝聚体区域中提取中心、界面和边界。

1.11.9 IntensityCalculation
用途：
计算 foci 局部信号和局部背景。

当前实现：
1. 每帧先对图像做 imgaussfilt，sigma = 1。
2. base_bkg 当前为整幅图像像素的 90 百分位，而不是 nucleus_mask 内均值；原 nucleus_mask 均值写法被注释。
3. foci 信号区域由 rna_width 决定。
4. 背景环由 bkg_width 决定。
5. rna_bkg 第一列为扣除局部背景后的 foci 总信号，第二列为局部背景均值。

1.12 结果检查和质量控制建议
每批数据运行完成后，建议按以下顺序检查：
1. 查看 Cell_analysis_errors.txt。如果存在失败细胞，先按错误信息定位是读取失败、核分割失败、spot 匹配失败、HMRF 空类别还是保存失败。
2. 查看每个细胞的 png 检查图。重点确认 foci 点是否落在真实信号上，凝聚体边界是否合理，是否存在明显错误核分割。
3. 查看 HMRFseg.png。若 HMRF 类别阈值太低，会把背景纳入凝聚体；太高则可能只保留极亮中心。
4. 查看 CDmask.tif。确认边界、中心和 mask 是否与原图一致。
5. 查看 roi-bicubic.tif 和 roi.tif。确认 ROI 是否完整包含 foci 附近区域。
6. 打开 .mat 文件检查 foci_result 和 condensate_result 是否存在，字段是否齐全。
7. 统计前先剔除明显定位错误、z 层错误、核分割错误、图像饱和、视野中多细胞干扰的样本。

常见问题和处理方式：
1. LoG 定位到异常亮杂点：重新裁剪图像，去掉杂点；或提高筛选条件，手动复查 quality。
2. nucleus_mask 选错细胞：重新裁剪单细胞；尝试换通道生成核掩膜；必要时手动圈核。
3. RNA 阴性细胞误判：Cell_with_RNA.txt 和 Cell_without_RNA.txt 应由人工判断后写入，脚本内自动判断只作为辅助。
4. z 层在边缘：若 foci 位于第一层或最后一层，可能受色差校正后的黑层影响，建议剔除或重新采集。
5. HMRF 无凝聚体类别：检查 seg_point 是否过高，图像是否过暗，PSF/去噪模型是否匹配。
6. 凝聚体过多：提高 seg_point、min_radius 或 min_partition_coefficient。
7. 凝聚体过少：降低 seg_point 或 min_partition_coefficient，但需避免把背景纳入。
8. 距离为负值：表示 foci 位于凝聚体 mask 内部，不是错误。
9. 后处理找不到 zstep：检查 zstep_sheet.csv、OCT4_label_z.xlsx 或 BRD4_label_z.xlsx 中的文件名是否与 .mat 文件名一致。
10. 输出 OME-TIFF 在 Fiji 中维度错乱：使用 Bio-Formats 打开，并核对 C/Z/T 顺序。

1.13 推荐交接运行模板
第一次拿到新数据时，建议不要直接批量跑全部数据，而按以下方式进行：
1. 先确认通道顺序和成像模式。
2. 使用 1-3 个代表性细胞试运行对应脚本。
3. 检查 ONNX 模型输入尺寸与图像尺寸是否匹配。
4. 检查 PSF 通道是否匹配。
5. 检查单细胞 png、HMRFseg.png、CDmask.tif。
6. 根据结果调整 seg_point、min_partition_coefficient、min_radius 和 roi_width。
7. 确认 Cell_analysis_errors.txt 没有系统性错误。
8. 再批量运行所有细胞。
9. 批量完成后人工复查失败细胞和可疑细胞。
10. 最后逐节运行后处理统计块并导出绘图数据。

1.14 当前代码中建议后续修正或确认的点
1. Step3_downstream_analysis/3color-Promoter_RNA_SCR/denoise_deconv_PRE_distance.m 调用了 log_detector_3d_Sage_v3，但当前 Function/CondensateAnalysis 目录中可见的是 log_detector_3d_Sage.m。若 v3 函数没有放入路径，脚本会报错。
2. 3color-Promoter_RNA_SCR 中 intensity(frame_iter) = rna_bkg(frame_iter, 1)/base_bkg 可能存在向量除法问题，建议改为 base_bkg(frame_iter) 或明确归一化公式。
3. 多个脚本中存在硬编码绝对路径，例如 D:\ImageData\Supplementary_Imaging_Data\ExampleData，需要运行前改为本地路径。
4. 多个后处理块需要手动切换 filepath、condensate、dna 和 infotable_path，建议每次运行前在文档或代码中记录当前分析对象。
5. filter_condensates_Area_PC.m 中中文注释有编码问题，建议统一为 UTF-8。
6. README 中 Step2 输出写的是 *-denoised.tif 和 *-denoised-deconv.tif，而 Step3 多数流程输出为 *-denoised.ome.tif 或 *-denoised-deconv.ome.tif；说明文档中应区分 Step2 和 Step3。
7. 4color DNA/RNA-2Condensate 输出目录名为 average_boundary，而 PRE-Condensate 输出目录名为 averaged_boundary；两者拼写不同，后处理时不要混淆。
8. 图像尺寸过小、ROI 靠边、foci 在 z 边缘、通道顺序错误，是最常见的批处理失败来源，建议在交接时提供一份“合格输入图像示例”和“不合格示例”。
